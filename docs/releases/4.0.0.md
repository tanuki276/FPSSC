# FSCSR 4.0.0

FPSSC の Android アプリ名を **FSCSR** に変更。APK: `FSCSR-4.0.0.apk`。
Android の applicationId (`com.tanuki276.fpssc`) とリポジトリ URL は更新互換性のため維持しています。

## 修正と追加

- ゲーム上の半透明 ON/OFF パネル。診断は小さく表示し、＋/− で詳細を展開・縮小。診断文字の領域はタッチを通し、操作ボタンだけがタッチを受け取ります。
- オーバーレイ自身の文字は画像認識から除外。前面判定ではアクセシビリティのオーバーレイウィンドウを除外します。
- 距離・偏差射撃・回避方向を画面高さ基準の等方座標で計算。送信時の二重の縦横比補正を回避。自機・敵・弾を同じカメラ補正座標で追跡。
- 低HP、赤/ピンクのHP、画面端の敵の検出条件を改善。赤/ピンクの移動弾を追加。
- ターゲット切り替えの抑制と急加速による過剰な偏差の抑制。射撃ジェスチャーは最短220ms間隔。
- レンガ・水の局所的な地形判定。進める方向の探索、壁越し射撃の抑制、750ms進めない場合の650msの方向転換。

## 使用方法

1. FSCSR を開き、操作サービスを有効化。旧版から更新した場合はサービスを OFF/ON。
2. 横画面で **画面共有を開始** → **画面全体**を選択。
3. ブロスタの練習場を開き、上部パネルの **自動 OFF** をタップして ON。
4. **診断 ＋** で詳細、**診断 −** で小さく表示。展開中は画像認識から除外される範囲が広がるため、通常は小さい表示を使用。
5. パネルの **自動 ON** をタップすると OFF。通知の **停止** で画面共有も終了。

## 検証と限界

公開ワークフローは JVM 回帰テスト、Android ビルド/lint、Android 30 エミュレーターの入力統合テストに成功した場合のみリリースします。
入力統合テストはオーバーレイの存在、移動の継続、同時攻撃、停止時の解放、古い判断・ゲーム以外への入力拒否を確認します。
提供済みの練習場静止画をローカルで確認しています。画像は公開していません。

**実機ブロスタの連続対戦は未検証です。全マップ・全キャラクターの戦闘性能を保証するリリースではありません。**
地形はレンガ/青い水の色判定で未知の壁には対応できません。弾の全種類、弾の所有者、キャラ固有の射程/弾速/装弾数、茂みの中の敵、メニューやマッチングは未対応です。

## インストール互換性

CI のテスト署名を使用した APK です。`SIGNING-CERT.txt` と `SHA256SUMS` を添付します。
以前のAPKと署名が異なる場合、上書き更新はできません。その場合のみ旧版を削除して再インストールしてください（設定は消えるため、操作サービスと画面共有を再設定）。正式な固定署名鍵を使う配布ではありません。
