# FPSSC 3.0.0

Android 単体の画面認識・自動操作アプリです。操作座標の手入力・保存は不要です。

## 変更内容

- 青・シアンの移動パッドと赤・オレンジの通常攻撃パッドを自動認識。輪郭だけのパッドにも対応し、3回の一致後に操作します。画面や配置が変わった場合は再認識します。操作中に動くつまみを基準点の移動と誤認しないよう、確認したパッド中心を維持します。
- 前面判定をイベント履歴からアクティブウィンドウのパッケージ確認に変更。ブロスタ以外には操作を送りません。
- 移動を毎回指を離すスワイプから、継続タッチに変更。射撃と同時操作し、停止・古い判断・前面変更時には移動を解放します。
- 取得した RGBA バッファから解析サイズへ直接変換し、全画面 Bitmap の作成と画素ごとの Android API 呼び出しを削減しました。端末での処理時間改善率は未測定です。
- Android 14+ のキャプチャサイズ変更に合わせて解析・操作位置を再取得します。
- 操作ボタンの候補数、直近のゲーム中の状態、タッチの送信・完了・中断回数を診断に表示します。
- 専用ランチャー／通知アイコン、3.0.0 のバージョン表示を追加しました。

## 入手と開始

`FPSSC-3.0.0.apk` をインストールし、アプリ内から FPSSC の操作サービスを有効にしてください。既存版から更新した場合、前面確認の権限を反映するため操作サービスを一度 OFF/ON してください。

横画面で「画面共有を開始」から **画面全体** を共有し、自動操作を ON にしてブロスタの練習画面に切り替えます。通知の「停止」で終了できます。座標の保存は不要です。

公開 APK は release ビルドですが **CI のテスト鍵による署名** です。Play ストア向けの秘密鍵は設定されていません。以前の APK と署名が異なり更新できない場合は、旧版をアンインストールしてからインストールしてください。署名証明書は `SIGNING-CERT.txt`、ファイルの SHA-256 は `SHA256SUMS` に添付しています。

## 検証範囲と制約

リリースは Java/.NET 回帰テスト、Android ビルド・Lint、Android エミュレーターのタッチ統合テストが通った場合にだけ公開します。統合テストは、継続移動・同時射撃・停止解放・古い判断の拒否・対象外アプリへの操作拒否をテスト用画面で確認します。提供された練習画面の静止画でも、画素変換からキャラ／操作ボタン検出と移動・射撃判断までを別途確認しています。

**ブロスタの実機・実戦での動作、勝率、全マップ／全キャラへの対応は確認していません。実用確認済みの完成版とは扱えません。** バージョン番号はその保証を意味しません。画面内の見える体力バーとパッドの色・形を利用する方式であり、学習済みモデルへの移行は行っていません。メニュー操作・自動マッチング・弾数管理・キャラ固有戦術は未実装です。Android 13 以下では回転後に画面共有の再開始が必要です。

アクティブウィンドウはパッケージ名の確認だけに使い、UI ツリーのテキスト・入力内容は走査しません。操作サービスと画面共有はユーザーが有効にした間だけ使います。
