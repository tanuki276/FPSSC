# FSCSR 5.0.0

`feature/vision-overlay-profiles` をもとにしたリリースです。APK: `FSCSR-5.0.0.apk`。
applicationId は `com.tanuki276.fpssc`、versionCode は `50000` です。

## 追加・変更

- 設定画面にキャラクター / 練習用戦闘プロファイルの選択を追加。選択は端末に保存し、オーバーレイと共有します。
- 小型の半透明オーバーレイに **AI ON/OFF**、キャラ選択、診断の展開ボタンを配置。キャラはタップで次、長押しで前に切り替えます。診断は展開時のみ表示します。
- 箱らしい物体、茂みの占有率、小さな移動物体の時系列診断を追加。候補数・安定検出数・信頼度を表示し、大きな画面変化による移動物体の誤検出を抑制します。
- オフライン練習用の戦闘プロファイル、相手の動きのモデル、短期戦術プランナー、弾数推定と射撃判断を追加。回帰テスト、決定的ベンチマーク、長時間ストレステストを含みます。
- 移動物体の回帰テスト画像を修正。背景との輝度差が検出しきい値を上回る配色に変更しました。

## 使用方法

1. FSCSR を開き、必要に応じて練習用プロファイルを選択。
2. 操作サービスを有効化し、横画面で **画面共有を開始** → **画面全体** を選択。
3. ブロスタの練習場を開き、上部パネルの **AI OFF** をタップして ON。
4. **診断 ＋** で認識・入力状態を確認。通常は診断を閉じて使用。
5. **AI ON** をタップして OFF。通知の **停止** で画面共有も終了。

## 検証と限界

公開は JVM / .NET 回帰テスト、Android ビルド・lint、Android 30 エミュレーター入力統合テストの成功後に実行します。

**選択プロファイルと新しい練習用戦闘ロジックは実際のタッチ制御には接続していません。**
実際の操作は従来の `AgentCore` を使用します。箱・茂み・移動物体の新しい認識結果も診断専用です。
プロファイル変更によって実際の射程・弾速・戦術が変わるものではありません。

実機ブロスタの連続対戦、全マップ・全キャラクターでの動作は未検証です。
色・形状・時系列のヒューリスティックに依存し、未知の地形や弾、隠れた敵を確実に認識できません。
エミュレーターと合成画像のテストは実機ゲームでの互換性や戦闘性能を保証しません。

## インストール互換性

CI のテスト署名を使用した APK です。`SIGNING-CERT.txt` と `SHA256SUMS` を添付します。
以前の APK と署名が異なる場合は上書き更新できません。その場合は旧版を削除して再インストールしてください
（設定は消えるため、操作サービスと画面共有を再設定）。固定の正式署名鍵による配布ではありません。
