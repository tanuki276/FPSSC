# FSCSR 5.2.0 — 味方自動追従と手動ピンズ

APK: `FSCSR-5.2.0.apk` / versionCode: `50200`。

## 追加した機能

- **味方追従モード**を追加。青いHP表示・白いHP文字・暗い枠から味方を検出し、自分や敵とは別に追跡します。
- 最寄りの味方を連続確認して追従を開始。一度選んだ味方は、他の味方が近づいてもすぐに切り替えません。
- 味方に近づくと停止し、離れると再び追従。見失った場合や自分の位置が不明な場合は停止します。
- 認識できるレンガ・水を避けて移動。追従モードは移動専用で、自動攻撃・必殺技を送りません。
- **ピンズ**ボタンで自動タッチを解放して手動操作へ移行。追従はONのまま保持し、ピンズを出した後 **再開** を押すと味方を再確認して追従します。
- 手動タッチで追従ジェスチャーが中断された場合も手動待機へ移行。時間経過だけで勝手に再開しません。
- オーバーレイと設定画面で **味方追従 / 戦闘** を切り替え可能。初期モードは味方追従。切り替え時は自動操作をOFFにします。

## 使い方

1. 設定画面で **味方追従** を選び、操作サービスと横画面の全画面共有を開始。
2. 味方の青いHP表示が見えるチーム戦を開き、オーバーレイの **AI OFF** を押してON。
3. ピンズを出す場合は上部の **ピンズ** → ゲーム内のピンズを手で選択 → 上部の **再開**。
4. 停止は **AI ON** を押してOFF、画面共有の終了は通知の **停止**。

## ピンズ操作の制約

Android の AccessibilityService.dispatchGesture は進行中の手動ジェスチャーをキャンセルします。
そのため、自動移動の指を保持したまま手指でピンズを同時操作できるとはしていません。
本版では追従設定をONのまま移動だけを一時停止し、明示的に再開する方式です。
ピンズの位置を固定した自動タップや自動送信は行いません。

公式仕様: https://developer.android.com/reference/android/accessibilityservice/AccessibilityService#dispatchGesture(android.accessibilityservice.GestureDescription,%20android.accessibilityservice.AccessibilityService.GestureResultCallback,%20android.os.Handler)

## 検証と限界

合成画素からの味方識別、味方確認、追従方向、対象維持、距離ヒステリシス、遮蔽停止、壁回避、手動ゲートを回帰テスト。
Androidエミュレーターでは、追従用の移動のみの入力、ピンズボタン、指の解放、手動タップ配送、明示的な再開を確認します。
既存の戦闘・認識・入力テストも維持。全CI成功後にAPKを公開します。

実機ブロスタでの連続動作は未検証です。味方の青いHP表示が隠れると追従できません。
最寄りの味方を自動選択し、任意の名前による指名には対応しません。地形認識は既知の色に限られ、迷路の全体経路探索ではありません。
CIのテスト署名を使用します。旧版と署名が異なる場合は上書き更新できません。
`SIGNING-CERT.txt` と `SHA256SUMS` を添付します。
