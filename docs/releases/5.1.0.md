# FSCSR 5.1.0 — 実操作の戦闘コントローラー更新

APK: `FSCSR-5.1.0.apk` / versionCode: `50100`。

## 5.0.0 との実際の違い

5.0.0 は新しい戦闘ロジックが実入力に接続されていませんでした。
今回は `LiveCombatController` を画面取得からタッチ送信までの経路に接続しています。

- 選択キャラの射程・弾速・射撃間隔・リロード時間・適正距離を実操作へ適用。
- 相手の速度・加速度・動きのモデルから偏差照準。画像キュー・処理・入力スライスの遅れを上限付きで補正。
- 短期戦術プランナーによる接近・距離維持・後退・複数弾回避と、敵を見失った際の追跡・探索。
- 遮蔽物のない敵を優先し、停止中も壁越し射撃を抑止。投擲は距離に応じてスティック量を調整。
- 実際に送信できた射撃から弾数を推定。入力拒否や準備中の判断で弾を消費しない。
- カメラ移動に合わせて敵の記憶位置を更新。標的変更時の照準混合を解消。
- 自動 OFF、操作位置未確定、自機未検出、古い画像では停止。必殺技・ハイパーチャージは未送信。

## 使い方

設定画面またはオーバーレイで実際に使用するキャラに近いプロファイルを選択してください。
操作サービスを有効にし、横画面の全画面共有を開始して練習場で **AI OFF** をタップ。
診断を展開すると `live practice:` に続く射程・命中見積もり・弾数・戦術が表示されます。

## 検証の範囲

既存回帰テスト、新しい実操作コントローラーテスト、画素→認識→戦闘判断の合成テスト、
旧ロジックとの閉ループ合成対戦比較を追加・実行します。
16通りの敵移動では、旧版/新版とも16勝、被弾40→0、射撃142→96、与ダメージ回数はともに96でした。
これは正確な敵位置を与えた障害物のない合成環境での結果です。
**実機ブロスタでの勝率や「超強い」性能を示す結果ではありません。**

Windows の Pyla-RL の偏差照準・射線判定・横回避設計を参照しました。
ソースや学習済みモデルはコピーしていません。認識は従来の色・HP表示ベースで、
遮蔽・未知の見た目・弾の所有者・マップ全体の経路探索には限界があります。
キャラ数値と弾数も推定値です。実機の連続映像による認識・入力・命中率の検証が必要です。
詳細は `docs/IMPLEMENTATION_REFERENCES.md` を参照。

CI の JVM/.NET テスト、Android ビルド・lint、エミュレーター入力統合テスト成功後に公開します。
CI のテスト署名を使用します。署名が異なる旧 APK とは上書き更新できない場合があります。
`SIGNING-CERT.txt` と `SHA256SUMS` を添付します。
